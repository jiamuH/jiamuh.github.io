# jiamuh.github.io

Personal website of Jiamu Huang, built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll template.
Pushing to `main` builds the site and publishes it to the `gh-pages` branch (`.github/workflows/deploy.yml`).

- Home page text: `_pages/about.md`
- Publications: `_bibliography/papers.bib` (refresh from NASA ADS: `cd ~/python && python3 -m website_tools.update_publications`)
- Photography page: `_pages/photography.md` (generated by `python3 -m website_tools.make_photography_page`; images in `assets/img/photography/`)
- CV: `assets/pdf/Jiamu_Huang_CV.pdf`
- Preview locally: `docker compose -f docker-compose-slim.yml up`, then open http://localhost:8080
